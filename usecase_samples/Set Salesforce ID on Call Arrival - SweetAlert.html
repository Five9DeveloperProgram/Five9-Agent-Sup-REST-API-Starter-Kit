Salesforce ID Campaign Script

This script will prompt for a Salesforce ID when a call arrives and set it as a CAV

IMPORTANT: The CAV "Salesforce.id" must exist in your domain and be set as read/write on the campaign profile layout.

How it works:

  1. When a call arrives, a SweetAlert popup will appear
  2. Agent enters the Salesforce ID into the popup
  3. The ID is automatically set as the "Salesforce.id" CAV
  4. The CAV can be used for screen pops, transfers, or dispositions
